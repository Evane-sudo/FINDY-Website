# Changelog - FINDY

Tous les changements importants de ce projet seront documentés dans ce fichier.

## [1.0.0] - 2024-05-27

### Ajouté
- Page d'accueil responsive avec hero section
- Section "À propos" avec statistiques
- Galerie interactive avec SVG
- Formulaire de candidature avec validation
- Section services avec 6 services principaux
- Section contact avec informations
- Navigation mobile avec hamburger menu
- Design mobile-first responsive
- Animations CSS fluides
- Système de notifications
- Support des fonts personnalisées (Bariol, Cooper)
- Configuration GitHub Pages
- Documentation complète (README, CONTRIBUTING, DEPLOYMENT)

### Design
- Palette de couleurs moderne (Primary: #FF6B6B, Secondary: #4ECDC4)
- Breakpoints responsive: Desktop, Tablet, Mobile, Small Mobile
- Animations au scroll avec Intersection Observer API
- Design animations et transitions fluides

### Responsive
- Desktop (> 1024px)
- Tablet (768px - 1024px)
- Mobile (480px - 768px)
- Small Mobile (< 480px)

### Technologie
- HTML5 sémantique
- CSS3 avec variables CSS
- JavaScript ES6+
- Fonts personnalisées (TTF)
- SVG pour les visuels

### Configuration
- package.json avec scripts npm
- .gitignore configuré
- GitHub Actions workflow pour tests
- LICENSE MIT
